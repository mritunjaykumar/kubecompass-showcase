UNDER THE HOOD
A clear path from
Markdown to meaning.
A retrieval-augmented generation pipeline separates finding evidence from composing an answer.
INDEX THE KNOWLEDGE 01—03
01 / INGEST
Read the docs.
Recursively discover local Markdown files from the Kubernetes documentation corpus.
Go · File discovery
02 / CHUNK + EMBED
Make content searchable.
Split text into overlapping chunks and generate vector representations of their meaning.
LangChainGo · nomic-embed-text
03 / STORE
Keep context together.
Persist document metadata, ordered chunks, and embeddings with transactional document updates.
PostgreSQL · pgvector
ANSWER THE QUESTION 04—06
04 / RETRIEVE
Find relevant passages.
Embed the question and rank stored chunks by cosine similarity using the matching embedding model.
Semantic search
05 / GENERATE
Answer with context.
Supply retrieved passages to the LLM, with instructions to cite evidence and acknowledge missing information.
Llama 3.2 · Ollama
06 / INSPECT
Follow the sources.
Display the generated answer alongside retrieved file paths and chunk numbers for review.
Go command-line interface


ENGINEERING WITH EVIDENCE
Retrieval quality
is part of the product.
KubeCompass includes an evaluation workflow so retrieval changes can be inspected against a repeatable set of Kubernetes questions.
Evaluation measures retrieval, not answer correctness. No performance or accuracy benchmark is claimed here.
Hit@1 / Hit@K
Does the expected document appear first, or within the top K retrieved chunks?
MRR@K
How highly does the first expected-document result rank?
JSON review reports
Inspect query results, ranks, similarity scores, and full chunk text to assess the evidence.

Markdown ingestion, semantic retrieval, LLM answers with source context, transactional storage, and a six-question retrieval evaluation seed set.
DESIGN CHOICE
Local models, inspectable sources
Ollama and PostgreSQL run locally in the current configuration. The application does not require a hosted AI API.
FUTURE WORK
More efficient indexing and broader validation
